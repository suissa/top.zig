# Overview Tab

## Purpose

The Overview tab is the default landing view. It answers: **is this host healthy, and where should I look next?**

## Data shown

- Total CPU usage and CPU count.
- RAM usage and total memory.
- Load averages (1/5/15 minutes).
- Uptime.
- Process count.
- CPU history.
- Memory history.
- Top CPU processes.
- Top memory processes.
- Disk pressure summary.
- Network RX/TX summary.
- Container/service health summary when integrations are available.

### Linux sources

- `/proc/stat`
- `/proc/meminfo`
- `/proc/loadavg`
- `/proc/uptime`
- `/proc/<pid>/*`
- later: `/proc/net/dev`, `/proc/diskstats`, PSI and cgroup v2

## TUI.zig widgets

Target composition:

- **Tabs / Navbar** — top-level tab navigation.
- **Grid** — responsive metric-card matrix.
- **Card** — CPU, memory, disk, network and service summaries.
- **ProgressBar** or custom gauge — CPU/RAM percentage.
- **Table** — compact hot-process list.
- **Badge** — warning/critical/healthy state.
- **Statusbar** — refresh rate, active sort/filter and shortcuts.
- **Custom Widget** — history sparklines and gradient gauges.

The current implementation already provides custom gradient gauges and CPU sparkline using low-level `Screen` drawing.

## Events

Global:

- `Tab` / `Shift+Tab`: change tab.
- Direct tab shortcut: select Overview.
- Mouse click: activate card/tab when mouse input is enabled.
- Resize: recompute responsive grid.

Local:

- `r`: force refresh.
- Enter on a summary card: open the related detailed tab.

## Styling

Default palette:

- Background: near-black blue.
- CPU: cyan → violet.
- Memory: green → cyan.
- Warning: amber.
- Critical: red.
- Muted metadata: blue-gray.

Use TUI.zig 24-bit RGB styles. Do not encode state by color alone; pair warning colors with text/badges.

## Layout

Wide terminal:

```text
Tabs
┌ CPU ───────────┐ ┌ MEMORY ────────┐ ┌ LOAD ──────────┐
├ history ───────┴─┴──────────────────┴─────────────────┤
├ Hot CPU processes ──────┬ Hot memory processes ───────┤
├ Disk ───────────────────┼ Network ─────────────────────┤
└ statusbar ──────────────────────────────────────────────┘
```

Narrow terminal:

- collapse metric cards vertically;
- reduce process tables to fewer columns;
- preserve CPU, memory and load first.

TUI.zig's Grid/Flex containers are the preferred target abstraction.

## Animation

- Gauge changes: short `easeOutQuad`/smooth interpolation.
- History: append rather than animate old samples.
- Critical state: subtle pulse, never aggressive blinking.
- Tab transition: optional 100–180 ms fade/slide when supported.
- Loading: Spinner/Skeleton only during initial collection or slow integrations.

## Status

**Partially implemented.** CPU, RAM, load, uptime, history and process table exist in v0.1. Disk/network/container summaries and true widget composition remain planned.
