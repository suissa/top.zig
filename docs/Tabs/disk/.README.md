# Disk Tab

## Purpose

Show both **capacity** and **activity** so a full disk and a saturated disk are distinguishable.

## Data shown

- Mounted filesystems.
- Used/free/total capacity.
- Read/write throughput.
- IOPS where derivable.
- I/O wait/pressure.
- Top processes by disk I/O.
- Later: filesystem type, inode usage and device temperature/SMART integration.

### Linux sources

- `/proc/mounts` or mountinfo.
- `statvfs`/filesystem stats.
- `/proc/diskstats`.
- `/proc/<pid>/io`.
- `/proc/pressure/io`.

## TUI.zig widgets

- **Table** — mounts/devices.
- **ProgressBar** — capacity per filesystem.
- **Card** — aggregate read/write throughput.
- **Badge** — read-only, full, pressure warnings.
- **SplitView** — devices vs top-I/O processes.
- **ScrollView** — many mounts.
- **Custom Widget** — throughput history graph.

## Events

- Up/Down: select filesystem/device.
- Enter: detail pane.
- `r`: sort by read throughput.
- `w`: sort by write throughput.
- `u`: sort by utilization/capacity.
- Mouse row selection/scroll.

## Styling

- Capacity: green < amber < red as utilization rises.
- Read: cyan.
- Write: violet.
- I/O pressure: amber/red.
- Keep throughput colors distinct from capacity colors.

## Layout

```text
┌ Capacity / I/O summary ────────────────────────────────┐
├ filesystems/devices (Table) ───────────────────────────┤
├ selected device throughput history ────────────────────┤
└ top process I/O ────────────────────────────────────────┘
```

## Animation

- Capacity bars interpolate.
- Throughput graph updates at sample cadence.
- Brief highlight on sudden I/O spike.
