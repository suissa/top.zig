# CPU Tab

## Purpose

Deep CPU inspection: total usage, per-core behavior, load and the processes consuming CPU.

## Data shown

- Overall CPU usage.
- Per-core utilization.
- User/system/idle/iowait percentages.
- 1/5/15 minute load averages.
- CPU history.
- Top CPU processes and threads.
- Later: frequency, temperature, scheduler/PSI pressure and steal time.

### Linux sources

- `/proc/stat`
- `/proc/loadavg`
- `/proc/<pid>/stat`
- later: `/sys/devices/system/cpu`, thermal/hwmon, `/proc/pressure/cpu`

## TUI.zig widgets

- **Card** — total CPU, load and pressure summaries.
- **Grid** — per-core gauges.
- **ProgressBar** — individual core percentages.
- **Table** — top CPU processes.
- **ScrollView** — many-core hosts.
- **Badge** — saturated/iowait/steal warnings.
- **Custom Widget** — CPU history chart/sparkline.
- **Tooltip** — explain user/system/iowait/steal when mouse is enabled.

## Events

- `c`: sort process table by CPU.
- Up/Down: process selection.
- Enter: process detail drawer/modal.
- `t`: toggle process/thread view.
- Mouse wheel: scroll cores/processes.
- Resize: change core grid column count.

## Styling

Per-core bars use a cold-to-hot gradient:

`cyan → violet → amber → red`

Threshold colors are visual guidance only; exact percentage is always displayed.

## Layout

Desktop-sized terminal:

```text
┌ Total CPU / Load / PSI ─────────────────────────────────┐
├ Core 0 ── Core 1 ── Core 2 ── Core 3 ...              │
├ CPU history ────────────────────────────────────────────┤
└ Top CPU processes (Table) ──────────────────────────────┘
```

On narrow terminals, per-core cards become a vertical/scrollable list.

## Animation

- Per-core ProgressBars interpolate to the latest sample.
- New hot-process rows may briefly highlight.
- CPU history itself should not shift with expensive per-cell animation; only append/update.
- Use a timer for refresh cadence independent from rendering cadence.

## Status

**Foundation implemented.** Overall CPU and per-process CPU sampling exist. Per-core breakdown, thread mode, PSI, frequency and temperature are planned.
