# Memory Tab

## Purpose

Explain where memory is going instead of showing only a single RAM percentage.

## Data shown

- Total / used / available RAM.
- Cache/buffers.
- Swap total/used.
- Memory history.
- Top RSS processes.
- Later: PSS/USS where available, cgroup memory, OOM events and memory PSI.

### Linux sources

- `/proc/meminfo`
- `/proc/<pid>/status`
- later: `/proc/<pid>/smaps_rollup`, `/proc/pressure/memory`, cgroup v2 memory files

## TUI.zig widgets

- **Card** — RAM and swap summaries.
- **ProgressBar** — RAM/swap usage.
- **Table** — memory-heavy processes.
- **Badge** — swap active, high pressure, OOM warning.
- **SplitView** — memory composition beside process table.
- **Custom Widget** — memory history/composition graph.
- **Modal** — selected PID memory details.

## Events

- `m`: sort by memory.
- Up/Down: select process.
- Enter: show process memory detail.
- `s`: toggle RSS/PSS when PSS support exists.
- Mouse selection and scrolling when enabled.

## Styling

- Normal RAM: green → cyan.
- High RAM: amber.
- Critical RAM/pressure: red.
- Cached/reclaimable memory uses muted colors so it is not visually confused with unreclaimable usage.

## Layout

```text
┌ RAM ──────────────────┐ ┌ SWAP ──────────────────┐
├ memory composition/history ───────────────────────┤
└ top memory processes ─────────────────────────────┘
```

## Animation

- Smooth gauge transitions.
- Optional composition transitions using `Animation(f32)`.
- OOM/pressure warnings may pulse briefly, then remain static.

## Status

**Partially implemented.** MemTotal/MemAvailable, used percentage and process RSS exist. Swap, composition, PSS/USS and PSI are planned.
