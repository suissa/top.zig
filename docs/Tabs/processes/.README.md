# Processes Tab

## Purpose

Interactive replacement for the process section of `top`/ `htop`.

## Data shown

Core columns:

- PID
- PPID
- user
- CPU %
- memory / RSS
- state
- command

Optional columns:

- threads
- elapsed time
- nice/priority
- read/write I/O
- cgroup/container
- systemd unit
- PM2 application/restart count

### Linux sources

- `/proc/<pid>/stat`
- `/proc/<pid>/status`
- `/proc/<pid>/cmdline`
- `/proc/<pid>/io`
- `/proc/<pid>/cgroup`

## TUI.zig widgets

- **Table** — primary process list.
- **InputField** — live process filter/search.
- **TreeView** — optional parent/child mode.
- **ScrollView** — large process sets.
- **Modal / AlertDialog** — PID detail and signal confirmation.
- **Badge** — process state/container/service.
- **Menu** — contextual actions.
- **Tooltip** — column explanations.
- **Statusbar** — current sort/filter and selected PID.

This tab should move away from hand-formatted text rows and use TUI.zig's Table once interaction is implemented.

## Events

- Up/Down: selection.
- PageUp/PageDown/Home/End: navigation.
- `c`: CPU sort.
- `m`: memory sort.
- `p`: PID sort.
- `/`: focus filter InputField.
- Enter: process detail.
- `t`: tree/flat toggle.
- `k`: signal menu.
- Delete or explicit action: SIGTERM/SIGKILL only after AlertDialog confirmation.
- Mouse click: select row.
- Mouse wheel: scroll.

TUI.zig's event model supports keyboard modifiers, special keys, mouse press/drag/scroll and resize.

## Styling

- selected row: high-contrast reverse/background.
- hot CPU: amber/red text or badge.
- zombie/stopped states: explicit textual badge.
- container/systemd/PM2 associations: muted colored badges.

## Layout

Wide mode shows all configured columns. Narrow mode progressively drops low-priority columns, preserving:

`PID CPU% MEM COMMAND`

A detail pane may use **SplitView** on wide terminals and **Modal** on narrow terminals.

## Animation

Keep the process table stable:

- do not animate row positions while sorting every frame;
- update/re-sort only on metric sample;
- briefly highlight newly hot processes;
- smooth numeric gauges only in detail view.

## Status

**Core collector implemented.** PID, PPID, command, CPU and RSS already exist. Interactive Table, selection, filter, tree view and process actions are planned.
