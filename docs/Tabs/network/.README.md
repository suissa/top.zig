# Network Tab

## Purpose

Expose host networking without requiring separate `iftop`/socket commands for basic diagnosis.

## Data shown

- Interfaces and link state.
- RX/TX bytes per second.
- RX/TX packet rates.
- Errors/drops.
- Interface history.
- Later: active sockets, listening ports and process/socket correlation.

### Linux sources

- `/proc/net/dev`
- `/sys/class/net/*`
- later: `/proc/net/tcp*`, `/proc/net/udp*`, netlink

## TUI.zig widgets

- **Table** — interfaces/sockets.
- **Card** — aggregate RX/TX.
- **Badge** — UP/DOWN, loopback, virtual, error state.
- **Tabs** (nested only if needed) — Interfaces / Sockets.
- **SplitView** — interface list + selected interface detail.
- **Custom Widget** — RX/TX history graph.
- **Tooltip** — address/flags/error explanation.

## Events

- Up/Down: interface selection.
- Enter: detail.
- `r`: sort by RX.
- `t`: sort by TX.
- `s`: switch to sockets view when available.
- Mouse selection and scroll.

## Styling

- RX: cyan.
- TX: violet.
- Drops/errors: amber/red.
- Down interface: dim gray.
- Virtual/container interfaces: distinct muted badge.

## Layout

```text
┌ Aggregate RX ↓ / TX ↑ ────────────────────────────────┐
├ Interfaces (Table) ──────────┬ Selected interface ────┤
├ RX/TX history ────────────────┴────────────────────────┤
└ sockets / top network processes (future) ─────────────┘
```

## Animation

- Throughput values interpolate only for display.
- Graph samples remain exact.
- Link state transitions can use a short color fade.

## Status

**Partially implemented.** Aggregate non-loopback RX/TX throughput is sampled from `/proc/net/dev` and rendered in live RX/TX cards. Per-interface tables, errors/drops, sockets and PID correlation remain planned.
